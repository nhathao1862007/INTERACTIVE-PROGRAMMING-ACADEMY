# Đóng góp — Trạm Dừng Tâm Hồn

Cảm ơn bạn muốn đóng góp! Vui lòng đọc [CODING_RULES.md](./CODING_RULES.md) trước.

## Quy trình

1. **Fork** repo & tạo branch: `feat/<mô-tả>` hoặc `fix/<mô-tả>`.
2. Cài đặt: `npm install`, chạy `npm run dev`.
3. Làm việc theo task trong `to-do-list.md`, đánh dấu `□` → `✅`.
4. Test:
   ```bash
   npm run lint
   npm run typecheck
   npm test
   ```
5. Commit nhỏ, mô tả rõ. Tạo PR với [CODING_RULES checklist](./CODING_RULES.md).

## Báo lỗi

- Mô tả: làm gì, trang nào, kỳ vọng gì, thấy gì.
- KHÔNG đăng dữ liệu cá nhân/nhạy cảm vào issue.

## Hành vi cộng đồng

Tôn trọng, không phán xét, bảo vệ quyền riêng tư của người dùng và người đóng góp.
